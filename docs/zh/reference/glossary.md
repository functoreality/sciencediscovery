# 术语表

| 术语 | 含义 |
|---|---|
| Project | 用于组织相关 Session 及其设置的顶层容器。 |
| Session | 一项任务的对话、工作区、历史、设置和产物。 |
| Skill | 可供运行使用的可复用指令和支持文件包。 |
| Specialist | 可选的专注能力，例如 Reviewer Specialist。 |
| Connector | 让产品访问外部数据源或服务的已配置集成。 |
| Reviewer | 审阅 Artifact 的 Specialist，例如检查引用格式和计算溯源。 |
| Workspace | Session 可用、并对其沙箱执行可见的文件。 |

生命周期和配置细节见[运行时行为](runtime-behavior.md)。
