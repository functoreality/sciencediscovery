# Glossary

| Term | Meaning |
|---|---|
| Project | A top-level container for related Sessions and their settings. |
| Session | A task conversation and its workspace, history, settings, and artifacts. |
| Skill | A reusable package of instructions and supporting files available to runs. |
| Specialist | An optional focused capability, such as the Reviewer Specialist. |
| Connector | A configured integration that gives the product access to an external source or service. |
| Reviewer | A specialist that checks an Artifact, such as citation format and computation provenance. |
| Workspace | The files available to a Session and visible to its sandboxed execution. |

For lifecycle and configuration details, see [Runtime behavior and limits](runtime-behavior.md).
